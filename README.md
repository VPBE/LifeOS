# ⚡ LifeOS — Your Life, Organized

A personal life-management dashboard built with plain HTML, CSS, and JavaScript.  
No frameworks. No backend. Just files, localStorage, and a clean dark UI.

## 🗂 Modules

| Module | Features |
|---|---|
| 🎓 School | Class Schedule · Assignments · Exam Countdowns · GPA Calculator |
| ✅ Productivity | To-Do List · Daily Planner · Habit Tracker · Pomodoro Timer |
| 📝 Notes | Quick Notes · Lecture Notes · Idea Vault |
| 💰 Finance | Income Tracker · Expense Tracker · Savings Goals |
| 🎬 Creator | Video Ideas · Hook Library · Upload Tracker · Earnings |

## 💾 Running Locally

No build step needed. Just open `index.html` in any browser,  
or use VS Code's Live Server extension.

## 📦 Deploying to Netlify

1. Push this repo to GitHub
2. Go to [netlify.com](https://netlify.com) → **Add new site** → **Import from Git**
3. Select your repo — leave all build settings blank
4. Click **Deploy site**
